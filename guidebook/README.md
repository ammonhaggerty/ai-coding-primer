# Intro to Full-Stack AI Product Development

A practical guide to building real products with Claude Code and Cloudflare — for designers, founders, PMs, researchers, hobbyists, and anyone with ideas who's been blocked by the technical wall.

---

## How to Read This

Start with the **TL;DR** if you want to get building immediately. Read **The Landscape** if you want to understand why this moment is different. Go straight to **Setting Up** when you're ready to get your hands dirty.

The chapters build on each other, but you can skip around. The **Appendices** are a reference you'll come back to.
