## Key Points

Six steps to a working setup:
1. Sign up for Claude (Pro $20/mo or Max $100/mo)
2. Install Ghostty (download from ghostty.org)
3. Install Claude Code (one command)
4. Clone the starter repo (one command)
5. Run `claude` — the AI Dev Intro Skill takes over
6. Start building

**Automated by skill/scripts:** OS detection, Node.js/nvm, Git, Wrangler, MCP servers, project scaffold, first deploy, verification.

**Requires human:** Account creation (Claude, Cloudflare, GitHub, Figma), permission approvals, deciding what to build.
