- Next phase: domain specialists 10-50x more effective (designer shipping code, researcher building tools, domain expert building what no engineer would think to build)

- Anthropic as closest example, still inventing the meta-workflow
- Opportunity to be early in defining how this works

### 6.5 — The Invitation
