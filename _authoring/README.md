# Authoring Materials

This folder contains working materials used during the writing of the guidebook. It's not reader-facing — it's for contributors and for preserving the editorial history.

## What's Here

```
_authoring/
├── outline.md              # The original article outline (v4) — the source of truth during writing
├── tasks.md                # Task breakdown with phases and dependencies
├── notes/                  # Per-chapter outlines, discussion notes, and approach docs
│   ├── 00-framing.md       # Framing & thesis (folded into the guidebook README)
│   ├── 00-tldr.md
│   ├── 01-about-the-author.md
│   ├── ...
│   └── 08-appendices-*.md
└── resources/              # Reference materials organized by chapter
    ├── about-the-author/   # Bio, professional history, talks, articles
    ├── the-landscape/      # Market context, capability research
    └── ...
```

## How This Was Used

Each chapter started as a notes file (the original README from that section's folder) with key points, status, and discussion notes. Resources were dropped into the corresponding subfolder before writing sessions. The outline served as the source of truth until drafts were written.

Now that the guidebook chapters exist as standalone files in `guidebook/`, this folder is archival. But it's still useful for understanding editorial decisions and for contributors who want context on why chapters are structured the way they are.
